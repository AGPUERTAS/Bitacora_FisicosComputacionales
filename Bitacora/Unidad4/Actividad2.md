 ## **Reporta en tu bitácora**
GLFW es una biblioteca multiplataforma la cual se encarga de crear ventanas, manejar el teclado, el mouse y llevar a cabo el contexto OpenGL, esta biblioteca cuenta con dos archivos: 
- **glfw3.lib:** Le muestra al compilador donde estan las funciones de GLFW

- **glfw3.dll:** Con tiene el codigo que se usa en tiempo de compilacion.
